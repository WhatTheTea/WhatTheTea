	\textbf{Desktop}: I built commercial desktop application to display Bluetooth devices charge information from ground up using WinUI 3 and Windows App SDK APIs. Application uses MVVM pattern, reactive programming and is covered with unit and UI tests. I implemented low-level device communication and reverse engineered proprietary Bluetooth protocols.
	
	\textbf{DevOps \& Infrastructure}: Engineered a centralized, version-controlled Azure DevOps YAML pipeline ecosystem to migrate legacy, project-specific Classic configurations. 
	\begin{itemize}
		\item \vspace{-.5em}\textbf{Pipeline Architecture}: Decomposed the system into reusable steps with aggregation into master-templates to eliminate configuration drift and human errors across multiple desktop products. 
		\item \vspace{-1em}\textbf{Session Troubleshooting}: Resolved complex UI session limitations on Windows agents to enable stable automated desktop UI testing. 
		\item \vspace{-1em}\textbf{Workflow Integration}: Utilized the Azure DevOps REST API to optimize the developer experience, enforce company workflow gates, and thoroughly documented the architecture in the internal wiki to ensure smooth onboarding.
	\end{itemize}	
	\vspace{-.5em}
	\textbf{Web \& AI}: I architected enterprise RAG microservice using FastAPI, PostgreSQL, SentenceTransformers and unstructured.io to provide embeddings to chatbot from external sources. The service is containerized and has recurrent behavior that can be configured without redeploying the service.  

	\textbf{Legacy Modernization}: Overhauled the architecture of a legacy 6k LoC monolithic UI component in screenshot taking application from 2016. Isolated separate viewer/editor concerns, eliminated complex UI code-behind graphic calculations, and implemented a clean data-driven architecture. Isolated components were shipped incrementally to keep the smooth transition, so application is more stable and maintainable now.
